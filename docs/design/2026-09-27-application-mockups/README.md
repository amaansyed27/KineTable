# Kinetable application mockups

The complete visual reference set for the pre-Slice-11 UX correction pass, generated on 27 September 2026: 18 desktop screens and 2 mobile screens.

Based on the [product/UX audit](../../reviews/2026-09-27-product-ux-audit.md), the existing landing-page visual language, and the approved application design brief. Wiring and Explain use their refined final versions.

These images establish interface hierarchy, materials, physical composition, and contextual interactions. Exact connector geometry and electrical connectivity follow the hardware model. Project and provider states are illustrative.
